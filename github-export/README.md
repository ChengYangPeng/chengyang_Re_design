# chengyangpeng.com — homepage redesign (v4)

Static site. `index.html` + `support.js`, no build step.

## Deploy on GitHub Pages
1. Push these files to the repo root on `main`.
2. Repo Settings → Pages → Source: "Deploy from a branch" → `main` / root.
3. Site will be live at https://chengyangpeng.github.io/chengyang_Re_design/

## Push from your machine
```bash
git clone https://github.com/ChengYangPeng/chengyang_Re_design.git
cd chengyang_Re_design
# copy index.html, support.js, README.md into this folder
git add . && git commit -m "Homepage redesign v4" && git push
```
